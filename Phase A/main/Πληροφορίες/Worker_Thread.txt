1️⃣ Τι είναι το Worker_Thread

    Το Worker_Thread είναι ένα thread που τρέχει ξεχωριστά από το κύριο πρόγραμμα (τον Worker server).

    Κάθε φορά που ο Master συνδέεται με τον Worker, δημιουργούμε ένα νέο Worker_Thread για να χειριστεί αυτή τη σύνδεση.

    Αυτό επιτρέπει στον Worker να χειρίζεται πολλούς Masters ταυτόχρονα.

2️⃣ Τι πληροφορίες χρειάζεται το Worker_Thread

    Για να δουλέψει σωστά, πρέπει να ξέρει:

        Με ποιον Master μιλάει → αυτό είναι το Socket

            Μέσω αυτού του socket διαβάζει και γράφει δεδομένα

            Είναι σαν το “τηλέφωνο” του thread με τον Master

        Που θα αποθηκεύει τα παιχνίδια → αυτό είναι το Map<String, Game>

            Όλα τα threads μοιράζονται αυτό το Map

            Κάθε φορά που προσθέτει ένα παιχνίδι, το βάζει εκεί

3️⃣ Τι κάνει το run() method

    Το run() είναι η μέθοδος που τρέχει όταν ξεκινήσεις το thread (thread.start())

    Μέσα στο run():

        Ανοίγει streams για να διαβάσει/γράψει δεδομένα από/προς τον Master

        Διαβάζει το request που έστειλε ο Master (π.χ. ADD_GAME)

        Αν το request είναι ADD_GAME:

            Παίρνει το JSON του παιχνιδιού

            Δημιουργεί ένα Game αντικείμενο

            Το προσθέτει στο Map

            Μπορεί να στείλει απάντηση πίσω στον Master (π.χ. “Game added successfully”)

4️⃣ Γιατί χρειάζεται να δώσουμε το Map στον constructor

    Όλα τα threads προσπελαύνουν το ίδιο Map για να αποθηκεύουν και να διαβάζουν τα παιχνίδια

    Αν κάθε thread είχε δικό του Map, δεν θα μοιράζονταν τα παιχνίδια με τα υπόλοιπα threads

    Έτσι, δίνουμε το ίδιο Map σε κάθε thread μέσω του constructor

5️⃣ Παράδειγμα analog

    Σκέψου:

        Worker server = ρεσεψιόν σε ξενοδοχείο

        Master = επισκέπτης

        Worker_Thread = υπάλληλος ρεσεψιόν που εξυπηρετεί έναν επισκέπτη

        Ο υπάλληλος παίρνει τα αιτήματα του επισκέπτη

        Κρατάει τα στοιχεία στο βιβλίο (Map) που μοιράζονται όλοι οι υπάλληλοι

        Έτσι, πολλοί υπάλληλοι μπορούν να εξυπηρετούν πολλούς επισκέπτες ταυτόχρονα, χωρίς να χάνονται τα στοιχεία.
